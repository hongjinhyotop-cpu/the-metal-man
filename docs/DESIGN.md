# The Metal Man — 설계 문서

> 다음 개발 세션이 가장 먼저 읽는 문서입니다. 단계(M1~M8, M7.5·M8a/b 포함)를 진행할 때마다 "진행 현황"과 "구조" 절을 갱신하십시오.

## 1. 게임 소개

- 한반도 전쟁이 터진 직후 **72시간** 동안, 국군 **K1A2 전차 소대장(소위)** 이 되어 전차 4대와 승무원을 지휘하는 워게임.
- **전투**: 2D 탑다운 지도 + 무전 지휘. 일시정지 가능한 실시간.
- **전투 사이**: 정비, 보급, 승무원 관리.
- **소대 편성**: 4대, 2개 조
  - 1조: 1호차(소대장차), 2호차
  - 2조: 3호차, 4호차(부소대장차)
- **지형(가상)**: 남쪽 주둔지, 가운데 논과 저수지가 있는 개활지, 북쪽 능선과 소도시, 서쪽 하천.
- 화면의 모든 글자는 **한국어**.

## 2. 기술 조건

- HTML, CSS, JavaScript 만 사용. 설치·빌드 과정 없음.
- GitHub Pages 에서 그대로 동작 (저장소 루트의 `index.html` 이 시작 페이지).
- `index.html` 을 더블클릭해 파일로 열어도 동작해야 한다 → **ES 모듈(import/export)을 쓰지 않고**, 일반 `<script>` 를 순서대로 불러와 전역 이름공간 `TMM` 하나에 기능을 붙인다.
- 파일은 기능별로 나눈다 (아래 "구조").
- 디자인: 군용 전술 지도 느낌. 어두운 올리브·녹색 계열, 모노스페이스 숫자, 각진 패널. 흔한 웹사이트 느낌(둥근 카드, 밝은 배경, 그라데이션 버튼)은 피한다.

### M1 지도와 이동 (완료)

- 가상 지형 지도 한 장: 개활지, 논, 숲, 능선, 도로, 하천+다리(2곳), 저수지, 소도시, 주둔지.
- 아군 K1A2 전차 4대. 호차 번호 꼬리표, 조별 색 (1조 황색 `#e2c35a`, 2조 청록 `#6fc7bf`).
- 전차 클릭(또는 숫자키 1~4)으로 선택, 지도 클릭으로 이동. A* 경로 탐색(비용 = 이동 시간).
- 지형별 속도 (km/h): 도로 45, 개활지 25, 주둔지 25, 다리 20, 시가지 15, 능선 12, 논 8, 숲 8, 하천·저수지 통행 불가.
- 스페이스바: 일시정지/재개. 처음에는 "작전 대기"(정지) 상태. 정지 중에도 이동 지시 가능.
- 오른쪽 패널: 선택 전차 정보(호차, 역할, 조, 상태, 위치 지형, 격자 좌표, 고도, 속도, 방향, 목적지, 남은 거리·시간), 소대 현황, 무전 기록, 조작법, 지형 범례.
- 부가: 시간 배속 ×1/×2/×4, S 키 정지, Esc/오른쪽 클릭 선택 해제, 커서 아래 지형 표시.

### M2 사격과 피해 (완료)

- **적**: 북한군 천마호 전차 1개 소대(4대, `js/units/enemy.js`). 매봉 능선 고갯길·새터읍에서 출발해 남쪽 아군 주둔지로 전진. M2 에서는 항상 보임.
  - 지도 기호: 붉은 마름모(적대 부대 기호) + 기갑 타원 + 번호 꼬리표. 격파되면 회색 + 붉은 X.
- **적 AI** (`js/ai/enemy-ai.js`): 전진(advance) → 아군이 2.8km 안에 들어오면 정지(engage), 처음 한 번은 횡대로 옆으로 250m씩 벌려 섬(deploy) → 정지 사격. 천마호는 기동 간 사격 안 함.
  - 후퇴(retreat): 주포 손상, 탄약 소진, 부위 2곳 이상 손상, 또는 소대 절반 이상 격파 + 자신도 손상 → 매봉 능선 고갯길 집결지(106.5, 6)로 물러나 그 자리에서 버팀(사거리 안이면 사격).
  - 고착(hold): 궤도가 끊기면 그 자리에서 사격만.
- **사격** (`js/combat/gunnery.js`): 아군 전차를 선택하고 적 전차를 클릭하면 사격 목표 지정(실선). 지정 목표가 없거나 사거리 밖이면 사거리 안의 가장 가까운 적과 자동 교전(점선). X 키로 지정 해제.
  - 표적이 바뀌면 조준 시간, 한 발 쏘면 장전 시간. 정지 중에는 차체 정면을 표적 쪽으로 돌림(정면 장갑으로 받기 위해).
  - K1A2 는 기동 간 사격 가능(명중 ×0.8).
- **탄종** (Q 키로 전환, 전환 시 3초 재장전): K276 날개안정분리철갑탄(전차용, 사거리 3.0km), K277 고폭다목적탄(장갑차·건물·보병용, 사거리 2.5km, 관통력은 거리 무관, 외부 장비 손상 잦음).
  - K1A2 는 120mm 탄 32발 = K276 20발 + K277 12발 (배분은 게임용 추정치). 쓰던 탄종이 떨어지면 남은 탄종으로 자동 전환. 둘 다 없으면 사격 불가.
- **명중·관통** (`js/combat/ballistics.js`, 수치표 `js/combat/weapons.js`):
  - 명중 확률 = 거리별 곡선(탄종별) × 사수 이동 중 배수 × 표적 이동 중 배수 × 사격통제장치 손상 배수(×0.5). 2%~97% 로 제한.
  - 맞은 면 = 표적 차체 방향과 '표적→사수' 방향의 각도: 50° 이내 정면, 130° 이상 후면, 그 사이 측면.
  - 관통 확률 = 표[탄종][표적 차종][면] 의 500m 값과 최대 사거리 값을 직선 보간.
  - 관통 시 차종별 확률(K1A2 30%, 천마호 65%)로 격파, 아니면 맞은 면에 따라 부위 1곳(40% 확률로 2곳) 손상. 관통 못 해도 탄종별 확률로 외부 장비 1곳 손상.
  - 근거 없는 숫자는 코드에 모두 "게임용 추정치" 주석.
- **부위별 손상** (`js/combat/damage.js`): 궤도(이동 불가) / 엔진(속도 ×0.5) / 주포(사격 불가) / 사격통제장치(명중률 ×0.5) / 무전기(M4: 명령 수신 불가·시야 공유 불가) / 격파.
  - 지도 기호 아래 작은 칸 5개(궤도·엔진·주포·사통·무전 순)로 손상 표시. 격파는 붉은 X.
- **무전 기록**: 사격·명중·손상을 짧은 문장으로 ("2호차 적 전차 3 격파. (철갑탄, 2.1km)"). 적의 빗나간 포격은 전차마다 게임 60초에 한 번만 기록.
- **승패** (`js/game/battle.js`, `js/ui/result.js`): 적 4대 모두 격파 → 작전 성공, 아군 4대 모두 격파 → 작전 실패. 결과 화면(격파·손실·탄약·명중률·경과 시간, 다시 하기).
- **정보 창**: 선택 전차의 전투 상태, 잔탄(탄종별 막대), 현재 탄종, 사격 목표, 명중 예상, 사격 상태(조준·장전 초), 부위별 손상. 소대 현황에 상태 배지·잔탄, '적 현황' 칸 추가. 적 위에 커서를 올리면 거리·명중 예상 표시.
- **교전 중 시간 감속**: 적이 아군과 3.5km 안이거나 최근 30초 안에 사격이 있으면 실제 1초 = 게임 3초 (평소 10초). 상단에 '교전 중' 표시. `CONFIG.COMBAT_TIME_SCALE`.
- **사거리 원**: 선택 전차의 현재 탄종 사거리를 점선 원으로 표시.

### M2 균형 메모 (모의 전투 400회 결과)

- 아군이 주둔지에서 가만히 있어도 대개 이긴다(K1A2 가 3km 에서 먼저 쏘고, 정면 복합장갑이 115mm 를 거의 막음). 공개 평가상 그럴듯한 결과.
- 대신 측면을 보이면 크게 당한다(측면 관통 45~60%). 후퇴한 적은 집결지에 남으므로 플레이어가 쫓아가야 승리.
- 철갑탄 20발을 원거리에서 다 쓰면 고폭탄(2.5km)만 남아 사거리가 줄어든다 → 탄종 관리가 의미 있음.
- M3 에서 시야가 들어오면 교전 거리가 숲·시가지·능선 때문에 짧아져 위험도가 오를 것. 그때 다시 맞출 것.

### M3 탐지와 식별 (완료)

- **시작 화면**: 작전 설명 + 주간(09:00 개시)/야간(22:00 개시) 선택 → '작전 지도 열기' → 작전 대기(일시정지) 상태. `TMM.LIGHT` (sensors.js).
- **시선(LOS)** (`js/map/sight.js`): 관측자 눈높이 3m → 표적 윗부분 2.6m 직선.
  - 지형 높이가 시선보다 높으면 완전히 가림(능선). 숲(가림 높이 14m)·시가지(9m)·주둔지(4m)는 시선이 그 높이 아래로 지나갈 때 지나간 칸만큼 '가림 정도'가 쌓이고 1 이상이면 가림(숲 약 3칸, 시가지 약 2칸). 언덕 위에서 내려다보면 숲 너머가 보인다.
  - 관측자·표적이 서 있는 칸은 시선을 가리지 않는다(숲 가장자리에서 밖이 보임). 표적이 숲·시가지 안에 있으면 '은폐'로 탐지 거리가 줄어든다.
  - 시야용 높이는 `map.sightElev`: 지도 그림의 잔기복(0.06)을 0.012 로 줄인 높이. 그대로 쓰면 평야의 둔덕마다 시선이 막혀 평야 전체가 안 보였다.
  - 빠른 계산을 위해 1칸을 4×4 로 나눈 높이 격자를 한 번 만들어 쓰고, 같은 두 점의 결과는 캐시한다.
- **탐지** (`js/game/intel.js`, 수치 `js/combat/sensors.js`): 탐지 거리 = 관측 장비 × 표적 신호 × 은폐(숲 0.3, 시가지 0.55) × 이동 중 1.25 × (1 − 0.5 × 가림 정도). 사격 후 12초는 포구 섬광으로 은폐 무시하고 크게 보인다(주간 ×1.5, 야간 ×3).
  - K1A2: 주간 3.5km / 야간 3.5km(열상). 천마호: 주간 3.0km / 야간 1.8km. 보병 분대 신호 0.35, 트럭 0.9.
- **식별**: 보이는 동안 진행도가 쌓임. 식별 시간 = idBase × (0.4 + 거리km) × (1 + 2 × 가림) × 표적 배수(보병 1.6). idBase: K1A2 주간 3.0·야간 2.4초, 천마호 주간 3.5·야간 12초. 소대 안에서 가장 잘 보는 전차 기준.
  - 피아식별장치(`VEHICLES.iff`): K1A2·K2 는 아군이 탐지하는 즉시 아군으로 식별.
  - 지도에는 노란 사엽 기호 '?' + 글자 꼬리표(미상 표적 A, B…) + 식별 진행 막대. 식별되면 적은 붉은 마름모, 아군은 푸른 사각형(보병 X, 트럭 바퀴, K2 타원).
- **안개 전쟁·시야 공유**: 편(side)마다 접촉 표 `game.intel.friend/enemy`. 한 대가 본 것은 편 전체가 공유(아군은 전장관리체계, 적은 무전). 아무도 못 보면 마지막 위치를 흐린 점선 기호로 90초(`VISION.MEMORY_SEC`) 남기고 지운다. 보는 앞에서 격파된 표적은 잔해로 계속 표시.
  - **사격은 그 전차가 직접 볼 때만**(`Intel.sees`). 공유된 접촉이라도 안 보이면 못 쏜다.
  - 적과 비지휘 아군은 실제 위치로 그리지 않고 접촉 표로만 그린다. '교전 중' 시간 감속도 보이는 적만 따진다.
- **사격 규칙 변화** (`gunnery.js`):
  - 자유 사격(자동 교전)은 '적으로 식별된' 보이는 표적만, 2km 안에서만(`FREE_FIRE_M`). 전차 > 트럭 > 보병 순. 더 먼 표적은 플레이어가 지정해야 사거리(3km) 끝까지 쏜다.
  - 미상 표적도 클릭해 지정할 수 있다 → 무전·화면 경고. 쏘기 전에 아군으로 식별되면 '사격 중지!' 하고 지정 해제. 아군을 쏘면(맞든 빗나가든) **오인사격**: 붉은 큰 화면 경고 + 무전 기록 붉은 강조, 결과 화면에 횟수.
  - 아군 전차는 플레이어가 **지정한 표적에만 차체를 돌린다**. 자동 교전 때는 포탑만 돌아가므로 측면이 드러날 수 있다(적 AI 는 항상 차체를 돌림). 적 포수는 정면이 아닌 전차를 먼저 노린다.
- **명중 배수** (`Ballistics.hitChance(map, s, t, ammo, mods)`): 차체 엄폐 ×0.5, 가림 정도 g → ×(1 − 0.45·g), 표적 크기(보병 ×0.5, 트럭 ×0.9), 야간 천마호 ×0.7.
- **차체 엄폐**: 표적이 멈춰 있고, 표적에서 400m 안의 땅이 '차체(1.5m)로 가는 시선'을 막지만 포탑은 보일 때. 정보 창 '엄폐' 줄에 "▲ 차체 엄폐"/"노출", 지도 기호 아래 녹색 반원. 커서를 지형에 올리면 "북쪽에서 볼 때 차체 엄폐 지형"인지 알려준다(북·북동·북서 2km 가상 관측자).
- **시야 표시**: V 키. 선택 전차에서 안 보이는 곳을 어둡게(숲 사이로 일부만 보이는 곳은 옅게), 탐지 거리 원.
- **비지휘 아군** (`js/units/allies.js`, 사격하지 않음, 전장관리체계에 연결 안 됨 → 관측자 아님):

### M5 승무원과 신뢰도 (완료)

- **승무원** (`js/crew/crew-data.js` 명단·성격·대사, `js/crew/crew.js` 규칙 `TMM.Crew`, 수치 `TMM.CREW`): 전차마다 4명(전차장·포수·탄약수·조종수), 이름은 모두 가상. 1호차 전차장은 플레이어(소위).
  - 각자 숙련도·피로·사기(0~100)와 부상(없음·경상·중상). 실력 `eff = 숙련도(0.75+0.5·s/100) × 피로(20 넘으면 감소, 100 이면 ×0.7) × 사기(0.95+0.1·m/100) × 부상(경상 0.85, 중상 0.5)` — 보통 승무원이면 약 1.
  - 보직 → 성능: 전차장(무전 응답 지연·오청 `crewFactor`, 식별 시간 `idMul`, 피격 시 스스로 엄폐 확률), 포수(명중 `hitMul` = 0.7+0.3·eff, 조준 시간 `aimMul`), 탄약수(장전 시간 `reloadMul`, 탄종 실수 → 4초 더 걸림), 조종수(속도 `speedMul` = 0.8+0.2·eff — 엄폐 진입도 그만큼, 고장 → 25~45초 정비 조치 `unit.stall`).
  - 성격 효과(`traits`): 김태윤 명중↑·조준↓ / 이도현 장전 느림·탄종 실수·성장 ×3 / 박성훈 속도 ×1.1·이동 명령에 투덜(사기 낮으면 잦음) / 최민수 예상 밖 명령(철수·엄호 이동·미식별 표적·자유 사격·번복)을 되물어 3~5초 늦음 / 정우진 1.5km 밖 명중 ×1.18 / 한재민 피로 ×0.5 / 윤지호 반응 빠름(응답 ×0.8)이지만 숙련도 70 전까지 오청 ×1.25·오인 보고('적 전차 발견! …정정')·조기 사격(식별 70% 넘은 1.5km 안 미상 표적, 표적마다 한 번 확률 판정), 성장 ×2 / 송민혁 3호차 갈등(응답 2~5초 지연, 윤지호가 크거나 격파 2회 이상이면 줄어듦) / 임채운 3호차 사기 하락 ×0.55 / 서준호 속도 ×0.9·고장 ×0.2 / 장만석 자율 판단 ×1.2·명령 해석·제안 / 조현석 장만석이 멀쩡하면 4호차 조준·장전 ×0.9 / 문성빈 장전 ×0.85 / 류경호 장만석이 다치면 동요(실력 ×0.75, 사기 −25).
  - 피로: 게임 1분에 0.55, 교전 중 ×2.2 (부상자 ×1.5). 시작 피로 주간 10·야간 14. 고장은 움직이는 1초당 1/4000 × (2−eff) × 성격 배수. 사기: 피격 −6(관통 −10), 아군 전차 손실 −12, 격파 +8(다른 전차 +3), 승리 +10·패배 −10, 오인사격 −10.
  - 성장: 쏠 때·맞힐 때·격파·장전·명령 수행·기동 거리·생존에 숙련도가 조금씩 오른다 (높을수록 덜 오름).
- **신뢰도** (2·3·4호차, 0~100, 시작 60·55·30): 오르는 경우 — 손실 없이 임무 완수 +15(손실 있으면 +5), 위험할 때(90초 안 피격·손상·1.8km 안 적) 철수 명령 → 도착 +8, 지정한 표적 격파 +3. 내리는 경우 — 명령 2분 안에 이동·엄호 이동·철수 중 노출 상태로 격파 −10(그 밖의 손실 −4), 오인사격 −8, 45초 안에 행동 명령을 바꾸는 번복이 2번 쌓이면 −3. ±3 이상 바뀌면 무전 기록에 초록/주황 '신뢰도' 줄.
  - 효과: 오청 배수 `(1.4−0.4·eff) × (1.5 − 신뢰/100)`, 응답 지연 배수 `(1.3−0.3·eff) × (1.3 − 0.6·신뢰/100)`. 신뢰 25 아래면 가끔 "…다시 확인 바란다" 로 머뭇거림.
  - **장만석 상사**: 신뢰 50 아래면 이동 명령의 목적지를 325m 안의 더 나은 엄폐물(알려진 위협 — 없으면 북쪽 2km — 에서 차체 엄폐 > 안 보임)로 바꾸고 "소대장님, 저기보다 여기가 낫습니다" 로 통보(40~50 사이는 확률). 70 이상이면 시킨 대로 하고, 멈춰 있을 때 더 나은 진지를 먼저 제안(150초 간격, 한 전투 3번까지).
- **부상** (기본 난이도: 전사 없음): 관통되면 70% 확률로 1명(+25% 확률로 1명 더), 맞은 면에 따라 다치기 쉬운 보직이 다름(정면 포수·전차장, 측면 탄약수·조종수, 후면 조종수). 관통 못 해도 10% 경상. 격파되면 승무원 전원 경상·중상. 후송·복귀는 M7.
- **무전 대사** (`TMM.CREW_VOICE`): 복창 말투(최민수 "교범대로…", 윤지호 "수신! …바로 하겠습니다!", 장만석은 신뢰에 따라), 되묻기, 갈등(무전 너머 송민혁), 투덜거림, 탄종 실수("철갑탄… 아니 고폭탄 장전 완료!" → "…다시."), 잡담 12묶음, 격파 환호, 부상 보고, 고장. 무전 기록에서 승무원 말은 기울임(`kind: 'crew'`).
  - 유머 대사: 잡담은 교전이 아닐 때만(`Battle.inCombat` 거짓), 탄종 실수·갈등·환호의 긴 말투는 '격한 교전'(20초 안 피격·근탄 또는 1.5km 안 보이는 적)이 아닐 때만. 한 사람 한 전투 3번, 같은 사람 150초·누구든 45초 간격, 같은 잡담 묶음은 한 번. 격할 때는 "수신. ○○." 와 짧은 말만.
  - 2·3·4호차의 차내 대화는 지휘 전차와 교신이 될 때만 들린다.
- **화면**: 선택 전차 정보 창 맨 위에 신뢰도 막대(2·3·4호차, 등급·최근 변화 이유) + 승무원 카드 4장(보직·이름·계급·숙련/피로/사기 막대·부상/동요/지침 표시, 마우스를 올리면 성격). 소대 현황 줄에 신뢰·부상 수. 상태에 '정비 조치 중'. 결과 화면에 전차별 승무원 한 줄 요약("이도현 이병, 장전 20회, 장전 실수 2회. 많이 늘었다.").
- **이어 쓰기 준비**: `TMM.Crew.snapshot(game)` → `Battle.create({ crew: 저장값 })` 으로 숙련도·피로·사기·부상·신뢰를 다음 전투에 넘길 수 있다 (M7).

### M6 1호차 조준 화면 (완료)

- **핵심 — 주의력 배분**: 소대장은 1호차 전차장이기도 하다. Tab 으로 **지도 ↔ 조준 화면**을 오간다.
  - 조준 화면: 1호차는 **수동 사격** (플레이어가 직접 조준·발사). 대신 **무전 명령 불가** — 소대 전체 사격 통제(8·9·0)와 상황 보고 요구(R)만 단축키로 된다(받는 대상과 상관없이 `'ALL'`). 무전 지휘 창은 흐려지고 안내문이 바뀐다.
  - 지도 화면: 1호차는 포수 김태윤 상병이 지금처럼 알아서 쏜다. 다만 전차장이 표적을 잡아 주지 않으므로 **조준 시간 ×1.25, 명중 ×0.93** (`TMM.SCOPE.AUTO_AIM_MUL/AUTO_HIT_MUL`).
- **규칙** (`js/combat/scope.js`, 수치 `TMM.SCOPE`, DOM 없음 → 모의 전투에서도 씀): `game.scope = { open, az(포탑 방향), pitch, zoom, rx, ry(조준선 위치, 화면 너비 비율), settle, onId, laser, time, opens }`.
  - 조준경에 보이는 표적 = 1호차가 **직접** 보는 것(`game.vis.get(1)`). 숲·건물 사이로 일부만 보이면 잎·벽 무늬가 덮이고, 차체 엄폐면 아랫부분이 땅에 가린다.
  - 포탑: 조준선을 화면 가장자리(13%) 안으로 가져가면 그쪽으로 돈다(최대 시야각 × 1.4/초, 40°/초 한계, 실제 시간). A·D / W·S / 화살표도 됨. 휠·Z 배율: 광각 12°(×3) / 협각 4°(×10).
  - **레이저(L 또는 오른쪽 클릭)**: 조준선이 표적 위면 거리(±5m)를 재고 30초(게임) 동안, 표적·1호차가 120m 넘게 움직이기 전까지 유효. 사격통제장치 손상이면 고장. 표적이 아니면 지형까지 거리.
  - **명중** (`Ballistics.hitChance` 의 `mods.manual`): 포수 실력(`Crew.hitMul`) 대신 **조준 품질** = 거리(레이저 ×1, 눈대중이면 1km 마다 −22%, 최소 ×0.4) × 조준 안정(막 올림 ×0.7 → 1.3초 유지 ×1.2) × 원거리 × (가장자리 ×0.3). 레이저로 잰 움직이는 표적은 리드 자동 계산(×0.7 → ×0.9). 반동으로 쏠 때마다 안정은 0 으로.
  - 표적 없는 곳에 쏘면 탄 1발 낭비. 사거리 밖은 막는다. 장전은 그대로 탄약수(`Crew.reloadMul`)와 게임 시간.
  - **머리 숙임**: 조준 화면에 있는 동안 1호차는 조준경 시야 ±12° 밖을 잠망경으로만 본다 → 그쪽 탐지 거리 ×0.35 (`Scope.detectMul` → `Intel.pairVis`). 소대의 다른 전차가 본 것은 나침반 띠에 표시된다.
  - **원거리**: 2km 밖 직접 조준은 1km 마다 −40%, 레이저 리드도 2km 밖에서 점점 효과가 줄어 3km 에서 없음.
  - **식별**: 조준경 시야 안의 표적은 식별 시간 ×0.6(광각)·×0.4(협각), 조준선 바로 위면 ×0.3 (`Scope.idMul` → `Intel.pairVis`).
  - **일시정지 중에는 조준·사격·레이저 불가** (조준선도 안 움직임). 멈춰 놓고 조준하기 금지. 열어 보는 것은 된다.
  - 발사는 `Scope.fire` → `Gunnery.fireAt`(자동 사격과 같은 함수) → `shot` 사건(`manual: true`). 전투 틱 밖에서 생긴 사건은 `game.pendingEvents` 에 쌓였다가 다음 `Battle.step` 에서 무전·승무원·신뢰도 처리를 그대로 탄다.
- **화면** (`js/render/scope-view.js`, `TMM.ScopeView`): 화면 세로 줄마다 포탑 방향으로 지도를 앞에서부터 훑어(높이 버퍼) 땅·숲(들쭉날쭉한 나무 윗선)·건물을 칠하는 2D '가짜 3D'. 지면은 시야 격자를 이중선형 보간(`Scope.ground`)해 표적과 그림이 딱 맞는다. 서 있는 칸과 60m 안의 숲·건물은 그리지 않는다(시선 규칙과 같음).
  - 주간: 녹색·올리브, 멀수록 흐림. 야간: **열상(백열)** 흑백 — 엔진·바퀴·포구 섬광·불타는 잔해가 밝다, 잡음·주사선.
  - 표적 실루엣: 천마호(둥근 포탑)·K1A2/K2(각진 포탑)·트럭·보병 분대. 보는 각도에 따라 폭과 포신 방향이 바뀌고, 포탑은 쏘는 표적 쪽을 향한다(이쪽을 겨누면 포구가 보임). 식별 50% 전이고 1.1km 밖이면 형체만(덩어리). 이름표: 미상 `? B 63%` / 적 / 아군.

### M6 균형 메모

모의 전투 (40회씩, 승률 · 아군 평균 손실). '조준 화면' 전략은 숙련된 플레이어 흉내: 포탑 초당 40°, 표적을 찾아 조준선을 올리는 데 0.7초, 레이저, 1.3초 유지 뒤 발사. '서툰 조준'은 찾는 데 2초, 0.6초만 유지하고 쏨.

| 조건 | 주간 | 야간 |
|---|---|---|
| 가만히 — M5 와 같게 (지도 화면 포수 배수 끔) | 18% · 2.70대 | 50% · 2.20대 |
| 가만히 — M6 (지도 화면 1호차 포수 혼자: 조준 ×1.25·명중 ×0.93) | 18% · 2.75대 | 53% · 2.13대 |
| 1조 서·2조 동 엄호만 | 80% · 1.27대 | 90% · 0.78대 |
| **엄호 + 계속 조준 화면** | **90% · 0.53대** | **100% · 0.23대** |
| 엄호 + 목표 지정 (M5 최선) | 100% · 0.15대 | 100% · 0.35대 |
| 엄호 + 목표 지정 + 30초마다 조준 화면 ↔ 지도 | 98% · 0.40대 | 100% · 0.40대 |
| 계속 조준 화면만 (무전 지휘 없음) | 78% · 1.45대 | 88% · 1.30대 |
| 계속 조준 화면만, 서툰 조준 | 73% · 1.93대 | 78% · 1.20대 |

- **조준 화면을 안 써도 M5 수준**: 지도 화면의 1호차 포수 배수는 결과를 거의 바꾸지 않는다(같은 시드 ±3%).
- **잘 쓰면 이득**: 엄호 방향만 정하고 1호차를 직접 쏘면 손실이 1.27 → 0.53대(주간), 0.78 → 0.23대(야간)로 준다. 1호차가 2~3km 표적을 레이저로 재고 쏘기 때문 (지도 화면 포수는 2km 안만 스스로 쏨).
- **계속 조준 화면에만 있으면**: 지휘를 하는 것보다 손실이 4~10배(1.2~1.9대), 주간 서툰 조준이면 4판에 1판 꼴로 진다. 처음엔 '조준만'이 주간 100%·1.4대로 너무 강했다 — 1호차 혼자 2~3km 에서 적 2대를 잡으면 적 소대가 무너지기 때문. 그래서 넣은 것(게임용 추정치):
  - **머리 숙임**: 조준경에 붙어 있는 동안 1호차는 조준경 시야 ±12° 밖을 잠망경으로만 본다 → 탐지 거리 ×0.35 (`HEAD_DOWN_DETECT`). 소대의 가장 좋은 관측자가 좁은 곳만 보게 된다.
  - 2km 밖 직접 조준은 1km 마다 −40% (`LONG_LOSS_PER_KM`), 레이저 리드도 2km 밖에서는 점점 효과가 없어짐. 조준 안정 최대 배수 1.3 → 1.2.
- 이미 최선으로 지휘하는 경우(엄호 + 목표 지정)에는 조준 화면을 오가도 손실이 줄지 않는다(오히려 0.15 → 0.40, 주간). 조준 화면에 있는 동안 목표 재지정을 못 하기 때문. 모의 전투의 '30초마다 전환'은 기계적이라, 사람이 교전이 잦아드는 때를 골라 들어가면 더 나을 것이다.
- 더 어렵게: `TMM.SCOPE.HEAD_DOWN_DETECT` 를 낮추거나 `LONG_LOSS_PER_KM` 을 올린다. 조준 화면을 더 보람 있게: `SETTLED_MUL` 을 올린다.
- 모의 전투에서 조준 화면 쓰기: `TMM.Scope.open(game)` → 매 틱 `scope.az/pitch` 를 표적 방향으로(포탑 속도 제한), `TMM.Scope.update(game, 실제초)`, `TMM.Scope.lase(game)`, `scope.settle` 이 차면 `TMM.Scope.fire(game)`. 실제 초 = 게임 초 / 3(교전 중) 또는 / 10. 조준 화면에 있는 동안 `Command.issue` 는 사격 통제·보고만 써야 공정하다.

| 조준 화면만 (48) | 0% | 23% | **77%** (작전 1~5 고르게: 9·15·7·1·5) | 1.3대 |
| 가만히 (24) | 0% | 33% | 67% | 1.4대 |

| 작전 | 좋은 지휘 | 조준 화면만 | 가만히 |
|---|---|---|---|
| 1 첫 접적 | 0.3 | 1.4 | 1.6 |
| 2 지연전 | 0.8 | 1.1 | 1.1 (+ 실패 많음) |

- '좋은 지휘'의 부분 성공은 대부분 모의 전략이 공격 작전에서 남은 적 한두 대를 끝까지 못 찾아 시간이 다 된 경우다(사람이면 찾는다). 소대 붕괴는 주로 지연전에서 2대 이상 잃은 판이 이어진 것.
- **조준 화면만**은 엄호 방향을 못 정해 첫 접적·지연전에서 옆구리를 맞고, 공격 작전은 다른 전차가 안 움직여 실패 → 실패 여파로 다음 작전이 더 불리해진다.
- 조정 과정에서 바꾼 것(게임용 추정치): 첫 접적 적 4 → 3대. 지연전은 8대가 한꺼번에 오면 그냥 다 잡혀서(지연이 아님) 세 제대 9대가 0·3·10분에 잇따라 오게 하고, '끝날 때 2차 저지선 북쪽 = 고립(전차 유기)' 규칙을 넣었다. 늦게 오는 적은 도착 전에는 지도 밖(`ai.pending`, `exited`)으로 쳐서 보이지도 쏘지도 않는다(처음엔 지도 가장자리에서 기다리며 쏘는 버그가 있었다). 2조 시작 위치를 논 한가운데 → 농로 위로(논은 8km/h 라 물러날 수 없었음). 교량 사수에 북쪽 조 3대(옆구리). 공격 작전의 적은 매복(`fireM`: 새터읍 1.5km, 매봉 1.2km) — 가만히 있으면 안 끝난다.
- 모의 전투는 무작위 폭이 크다: 같은 조건 20판도 손실 평균이 ±0.4 흔들린다. 24판 이상으로 볼 것.
- 더 쉽게: 지연전 `waves`(campaign-data.js)의 대수, 매복 거리 `fireM`. 더 어렵게: 실패 여파(`Campaign.K.MAX_PRESSURE`, 진지 방어 `extra`).
- 훈련 모드는 M6 그대로다. 다만 탄종 자동 선택(가려진 표적 → 고폭탄)과 고폭탄 규칙이 전투 전체에 들어갔다.

  - **휴식**: 1시간마다 피로 −8·사기 +2 (안 쉬어도 −3). 2시간 이상 쉬면 '남겨서 싸움'을 고른 경상자가 낫는다(소대장은 1시간).
  - **부상자**: 중상 — 후송(1시간, 캠페인 끝까지 안 돌아옴) / 데리고 감(실력 ×0.5, 안 나음). 경상 — 남겨서 싸움(실력 ×0.85) / 후송(1시간, 1~2작전 뒤 '후방 대기'로 복귀). 후송자는 `state.evac`.
  - **승무원 배치**: 전차마다 좌석(K1A2 전차장·포수·탄약수·조종수, K2 전차장·포수·조종수). 좌석 선택 목록 = 지금 사람 / 다른 전차의 같은 보직(고르면 서로 맞바꿈) / 후방 대기 전원 / 대대 보충병(한 재정비 3명까지) / (탄약수만) 비워 둠. 전차장·포수·조종수는 비울 수 없다(확정 때 비어 있으면 보충병). 소대장은 1호차 전차장 고정.

### M7b 균형 메모 (모의 캠페인)

모의 캠페인 (`tools/sim-campaign.js`, 48판씩 — '좋은 지휘 + 추천 + 흑표'는 시드 두 묶음 96판). 전략은 M7a 메모와 같고, 재정비는 '추천대로 하기'(rec) 또는 아무것도 안 함(idle).

| 전략 | 임무 완수 | 부분 성공 | 소대 붕괴 | 끝까지 남은 전차 · 받은 K2 |
|---|---|---|---|---|
| M7a 좋은 지휘 (자동 재정비, 비교 기준) | 50% | 31% | 19% | 2.5대 |
| **좋은 지휘 + 추천 재정비 + 흑표 요청** | **90%** (88·92%) | 7% | 3% | 3.5대 · 0.4대 |
| 좋은 지휘 + 추천 재정비, 흑표 안 부름 | 73% | 10% | 17% | 3.2대 · 0.6대 |
| 좋은 지휘 + 흑표, 재정비 안 함 (보급·수리·휴식 없음) | 52% | 23% | 25% | 2.7대 · 0.7대 |
| 조준 화면만 + 추천 재정비 | 0% | 33% | **67%** | 1.8대 · 0.4대 |
| 가만히 + 재정비 안 함 | 0% | 8% | **92%** | 1.2대 |
| 가만히 + 추천 재정비 | 0% | 29% | 71% | 1.5대 |

- **좋은 지휘 + 재정비를 잘 고르면 M7a 보다 확실히 낫다**(50% → 90%). 대부분은 재정비에서 온다: M7a 의 손실·실패는 대개 고치지 못한 궤도·엔진 손상(지연전에서 느린 전차가 끝날 때 2차 저지선 북쪽에 고립 → 유기, 공격 작전에서 엄호 이동이 느려 시간 초과)과 중상자(실력 ×0.5)였다. 재정비를 안 하면 흑표를 불러도 좋은 지휘가 M7a 수준(52%)으로 돌아간다.
- **흑표**는 한 번뿐이지만 크다(73% → 90%). 거절(35%+)·도착 지연(전체 3~5분)·4분 체류로 묶었다.
- **조준 화면만·가만히는 여전히 대부분 무너진다**(67~92%). 다만 M7a(조준 화면만 77% 붕괴)보다 조금 덜 무너지는데, 추천 재정비가 중상자를 보충병으로 바꾸고 손상을 고쳐 주기 때문이다(전투 한 판만 놓고 보면 M7a 와 같은 결과 — 같은 시드 30판 비교).
- 조정 과정(게임용 추정치): 처음 값(재정비 6·8·4·6시간, 궤도 3·엔진 4시간, 휴식 −11/시간, 보급 36·60·84발, K2 기본 30%+성공 30%, 후송 0.5시간, 흑표 거절 25%·7분)으로는 좋은 지휘 92%·조준 화면만 붕괴 48% 로 너무 쉬웠다 → 시간 5·6·4·5, 궤도 4·엔진 5시간, 휴식 −8, 보급 30·48·66, K2 5%+성공 32%+격파 비율 20%(최대 60%), 후송 1시간, 흑표 거절 35%·4분. 재정비 자원만 줄여서는 좋은 지휘가 거의 안 변했다(이 전략은 잃는 게 적어서) — 흑표와 K2 확률이 더 큰 손잡이였다.

### M7.5 조작·화면 정리 (완료)

직접 해 본 결과 "어떤 키가 뭔지 기억이 안 남", "화면 정보가 너무 많아 어디를 봐야 할지 모름" 두 가지가 어려웠다. **게임 규칙·난이도는 바꾸지 않고**(전투 규칙 파일은 `battle.js` 의 기초 훈련 승패 건너뛰기 한 줄만) 조작과 화면 구성만 고쳤다.

- **마우스만으로 다 되게** (키는 몰라도 됨, 기존 단축키는 모두 그대로 동작):
  - 고르기: 지도의 전차 아이콘 클릭, 또는 무전 지휘 창의 큰 **[1조] [2조] [소대 전체]** 버튼 + 호차 버튼 4개. 처음부터 지휘 전차가 골라져 있다(`main.js createGame`). 조·소대를 고르면 정보 창은 그중 첫 전차(소대 전체면 지휘 전차).
  - **우클릭 메뉴** (`js/ui/context-menu.js` 그리기, 내용은 `main.js actions.openMenu`): 땅 → 이동·엄호(이쪽 지켜봐)·철수 | 엄호 이동(소대 전체)·흑표 지원 요청(캠페인) / 적·미상 표적 → 목표 지정(미식별이면 ⚠ 표시)·이쪽 엄호 / 내 전차 → (그 전차를 고르고) 정지·상황 보고·목표 해제 | 지휘 전차면 탄종 전환·조준 화면. 갈 수 없는 땅·받을 전차 없음은 회색 + 이유. 항목마다 단축키 표시, 메뉴가 떠 있을 때 그 글자 키를 누르면 실행(↑↓ Enter 도 됨). 메뉴 밖을 눌러 닫은 클릭은 지도 명령으로 이어지지 않는다(`justClosed`). 고른 명령(버튼으로 고른 이동 등)이 있을 때의 우클릭은 예전처럼 취소. 연막은 게임에 없어서 넣지 않았다.
  - **명령 버튼** = 아이콘(선 SVG) + 한글 이름 + 단축키, 마우스를 올리면 한 줄 설명(`title` + 안내 줄). 3열: 이동·엄호·철수 / 목표 지정·정지·상황 보고 / 엄호 이동·흑표 지원(덜 쓰는 것, 흐리게). 사격 통제 3개, **1호차 직접**: [조준 화면 Tab] [탄종 전환 Q].
  - **안내 줄** (`#guide`, 지도 아래, `CommandBar.update → guideText`): 지금 클릭하면 무슨 일이 생기는지. 우선순위 — 작전 종료 > 조준 화면(숨김) > 메뉴 > 마우스를 올린 버튼·메뉴 항목 설명 > 고른 명령("▶ 2조 · 엄호 — 지켜볼 방향을 클릭 · 우클릭/Esc 취소") > 커서 아래 전차·표적("클릭: 2조에게 목표 지정 (적 전차 3)") > 기본("2조 선택됨 · 지도를 우클릭해 명령"). 커서 아래 지형은 같은 줄 오른쪽에 작게.
  - 화면 단추: 맨 위 상태 표시가 곧 **일시정지/재개 단추**(`#run-state`: "▶ 작전 개시 / ▶ 재개 / ❚❚ 진행 중 ×1"), 지도 왼쪽 위 **[시야 표시 V]**, 조준 화면 왼쪽 위 **[◀ 지도로 Tab]**(`#scope-exit`).

### M8a 적 다양화 (완료)

M8 을 둘로 나눴다. M8a 는 새 적과 새 위협, 연막, 흑표 하향, 난이도 다시 맞추기. 마무리(M8b)는 아래 6절 메모.

- **새 적** (`weapons.js` 차종·탄·관통표, `sensors.js`, `enemy.js create` 의 `model`). 근거 없는 수치는 모두 "게임용 추정치" 주석.
  - **폭풍호** `POKPUNG`: 125mm(`AMMO.E125`, 115mm 보다 2km 밖에서 조금 낫게), 개량 조준경(야간 탐지 2.8km), 기동 간 사격(×0.35), 정면은 천마호보다 조금 단단. 수가 적은 선발대(작전 2·4·5 에 1대씩).
  - **천마-20** `CHONMA20`: 125mm + **불새-3 미사일** 2발(`VEHICLES.CHONMA20.missiles`), **능동방어체계** `aps { charges: 2, p: 0.75, vs: ['K277'] }` — 맞을 고폭탄을 요격(횟수 제한, 철갑탄은 못 막음, `gunnery.js fireAt`). 요격을 본 표적에는 승무원이 철갑탄으로 바꾼다(`pickAmmo`, `target.apsSeen`). 정면 복합장갑(K276 관통 0.72→0.48). 장전 8.5초.
  - **보병 대전차조** `ATINF` (cls 'infantry', soft): 대전차 로켓 `AMMO.ATR`(사거리 500m, 3발, 재장전 22초), 매복 거리 450m(`fireM`), 신호 0.26(숲 ×0.3 이면 K1A2 가 약 270m 에서야 봄), 로켓 섬광도 작다(`SIGNATURE.flash` 0.3, `intel.js`). **정면을 보이는 전차는 150m 안이 아니면 기다린다**(옆·뒤를 노림, `gunnery.js chooseTarget`). `route` 가 있으면 숲을 따라 매복 자리로 걸어간다(4km/h). 로켓을 다 쓰거나 사상자가 나면(50%) 흩어지고, 적 전차가 무너지면 모두 흩어진다(`enemy-disperse`, 지도에서 사라짐). 적 전차 '무너짐' 판정과 목표 띠·결과 화면의 전차 수에는 넣지 않는다.
  - 적 AI 갈래 `ai.kind`: 'tank' | 'atgm'(천마-20, 미사일 유도 중에는 멈춤) | 'atteam'.
- **공축 기관총** (`gunnery.js machineGun`, 수치 `MG`): 소대 전차는 주포와 따로, 보이는 '적으로 식별된' 보병을 700m 안에서 3초마다 쏜다 → 제압(14초 동안 로켓 못 쏨) 또는 사상자. 사격 금지면 안 쏜다.
- **불새-3 미사일** (`js/game/missiles.js` `TMM.Missiles`, 수치 `TMM.MISSILE`·`AMMO.ATGM`): 천마-20 이 멈춰서, 자기 눈으로 보이는 아군 전차가 1.2~4.5km 면(처음 본 뒤 25초, 그다음 28초 간격) 쏜다. **느리다(120m/s: 1.5km 13초, 3km 25초).** 날아가는 내내 쏜 쪽이 표적을 봐야 하고(시선·연막), 1초 끊기면 빗나간다(`missile-miss` why: smoke·cover·launcher). 발사 섬광을 아군이 보면 1~2초 뒤 **"미사일!" 경고**(`missile-warn`): 무전 기록 주황 줄 + 지도에 미사일·노린 전차 고리·남은 초 + 조준 화면 경고. 무전 받는 전차(2·3·4호차)의 전차장은 30%×판단력으로 스스로 연막(1호차는 소대장이 정함). 끝까지 유도되면 `Ballistics.resolveShot`(관통 정면 0.25·측면 0.92).
- **포병·정찰 드론·자폭 드론** (`js/game/indirect.js` `TMM.Indirect`, 수치 `TMM.INDIRECT`, 작전 설정 `op.fires`):
  - **포병**: 요청 → (드론 발견 100~160초 / 적이 보고 있는 채 150초 넘게 한자리 50~80초) 뒤 떨어짐. **떨어지기 35초 전 지도에 붉은 원 + 남은 초**(`arty-warn`). 반지름 90m 원 안에 6초 동안 8발. 직격(7m)은 윗면 관통 판정(`TOP_PEN`, 격파 ×0.5), 40m 안은 외부 장비 손상(궤도·무전기·사통·주포) 32%×가까움, 승무원 경상 10%(전차장이 다치기 쉬움). 포격 사이 120초, 작전마다 최대 3~4회.
  - **정찰 드론**: 경로를 돌며 아래 750m(숲 ×0.35·시가지 ×0.6·연막 0)를 8초 보면 '발견' → 적이 위치를 알고(`Intel.reveal`) 포병 요청, 그 위를 20초 돈다. 우리 전차 1.7km(야간 1.4km) 안이면 드론이 보인다(`drone-seen`). 쏠 수 없다.
  - **자폭 드론**: 적이 아는(없으면 가장 가까운) 전차로 35m/s 로 날아온다. 보이면(1km) 경고(`kami-warn`), 500m 안에서 전차장 12.7mm 가 2초마다 7%×전차장 실력으로 떨어뜨린다(움직이면 ×0.8, 소대장이 조준경에 있으면 ×0.4, 숲 ×0.7). 명중 80% × 숲 0.45·시가지 0.75 × 움직임 0.6 × 연막 0.4. 맞으면 윗면 관통 0.7, 격파 ×0.6, 부위는 사통·무전·주포·엔진. 빗나가도 30% 외부 장비 손상.
  - 직격·자폭 명중은 `shot` 사건(`indirect: true`, 탄 'ARTY'·'DRONE', 면 'top' — 승무원 부상표 `HURT_W.top`)으로 무전·승무원·신뢰도 처리를 그대로 탄다. 스스로 엄폐 이동은 하지 않는다.
- **연막** (`js/game/smoke.js` `TMM.Smoke`, 수치 `TMM.SMOKE`): 전차마다 작전당 2회(`unit.smoke`, 전투마다 새로 → 재정비 때 다시 채워짐, 재정비 소식에 한 줄). 명령 `smoke`(`orders.js`, 무전 종류 'smoke' — 이동 명령을 대신하지 않음). 전차 앞 45m(지켜보는 방향 → 가장 가까운 아는 적 → 차체 방향)에 반지름 95m, 4초에 퍼져 80초. 연막을 지나는 시선은 모두 가린다(`Intel.pairVis` → 보이지도, 쏘지도 못함). 미사일 유도 끊김, 정찰 드론 못 봄, 자폭 드론 ×0.4.
- **화면** (M7.5 간단 보기 원칙):
  - 명령 버튼 3×3: 이동·엄호·철수 / 목표 지정·정지·상황 보고 / **연막 G**·엄호 이동·흑표 지원. 내 전차 우클릭 메뉴에 '연막 (n회 남음)'. 선택 요약 한 줄에 '연막 n'. 단축키 G(조준 화면에서도 내 전차 연막).
  - 경고는 **지도 위 표시 + 무전 기록 주황 줄**(`kind: 'threat'`, `radio-log.js` IMPORTANT). 큰 팝업 없음. 조준 화면에는 테두리 경고(`alertScope`). 지도 그리기는 `js/render/threat-layer.js`(`TMM.ThreatLayer`): 연막 구름, 포격 원·남은 초, 포탄 폭발, 경고가 뜬 미사일(남은 초), 우리가 알아챈 드론. 새 적 기호: 대전차조는 마름모 안 X, 천마-20 은 작은 화살, 이름표(폭풍호·천마-20·대전차조).

작전별 평균 손실 (좋은 지휘 + 흑표): 1 첫 접적 0.22 · 2 지연전 0.52 · 3 교량 0.14 · 4 새터읍 0.48 · 5 매봉 0.58. 같은 조건을 두 번 돌리면 완수율이 ±3%p 흔들린다(앞선 판 71%).

- **흑표 차이 4%p** (69 vs 65, 앞선 판 71 vs 63 — 목표 10%p 안). M7b 에는 73% → 90%(17%p). 흑표 하향만으로 지연전 손실이 0.4 → 1.0 대로 늘어서, 지연전 3제대를 3 → 2대로 줄여 맞췄다.
- **캠페인 전체로는 대처 여부 차이가 작다**(69 vs 68): 새 위협 피해가 전체 손실에서 차지하는 몫이 작고, 지연전에서는 포격을 피해 움직이는 게 오히려 손해일 때가 있기 때문. 위협이 몰린 작전만 보면 차이가 뚜렷하다 — M8b 에서 위협 피해를 키울지 검토.
- **작전 단위로는 대처하면 확실히 준다**: 매봉 능선(미사일·자폭 드론) 새 소대 한 판 손실 1.13 → 0.79(대처), 자폭 드론 격파 7 → 0(24판). 교량 사수(드론·포병) 포격 피해 부위 22 → 9, 손실 0.44 → 0.19(32판). 다만 지연전에서는 적과 맞서는 중에 포격을 피해 움직이면 옆구리를 보여 오히려 손해 — 봇은 2km 안의 적과 싸우는 중이면 자리를 지킨다.
- 조정 과정(게임용 추정치): 처음 값으로는 좋은 지휘 완수 21% 였다. 125mm 정면 관통 0.22 → 0.13, 명중 곡선을 115mm 에 가깝게, 폭풍호 기동 간 사격 0.5 → 0.35, 천마-20 정면(K276) 0.5 → 0.72, 미사일 4 → 2발·정면 관통 0.4 → 0.25·속도 180 → 120m/s(사람이 대처할 틈), 대전차 로켓 측면 0.6 → 0.5, 매봉 능선 적 4 → 3대, 새터읍 폭풍호 2 → 1·대전차조 5 → 4, 자폭 드론 4 → 3대, 포격 원 110 → 90m·8발·경고 35초. 모의 봇도 고침: 목표 지정은 전차만(보병을 지정하면 차체가 보병 쪽으로 돌아 적 전차에 옆구리를 보임), 지연전 4호차는 처음부터 동쪽 엄호.
- 더 어렵게: `TMM.MISSILE`(발수·`AUTO_SMOKE_P`), `TMM.INDIRECT.ARTY`(`WARN_SEC`·`RADIUS_M`), `VEHICLES.CHONMA20.aps`, 작전의 `fires`·`enemiesExtra`. 더 쉽게는 반대로, 또는 `TMM.SMOKE.CHARGES`.


## 4. 핵심 규칙과 수치

- 지도: 160 × 120 칸, **1칸 = 50m** → 8km × 6km. 좌표 단위는 "칸"(실수). x = 서→동, y = 북→남.
- 격자 좌표: 6자리 `EEE-NNN` (100m 단위, 남서쪽 모서리 기준, 북쪽으로 갈수록 N 증가). 1km 격자선 표시.
- 무전: 모든 지연은 게임 초 (교전 중 실제 1초 = 게임 3초라 명령 한 번에 실제 2~4초 정도). 수치는 `js/radio/radio-config.js` 한곳.
- 시간: 실제 1초 = 게임 10초 (`CONFIG.TIME_SCALE`), 교전 중에는 3초 (`CONFIG.COMBAT_TIME_SCALE`), 배속 곱함. 작전(72시간)은 D+0 05:00 기준, 이번 전투는 주간 09:00 / 야간 22:00 에 시작.
- 거리 계산: 칸 거리 × 50m. 사거리 K276 3.0km, K277 2.5km, 천마호 115mm 3.0km(2km 밖은 명중 거의 기대 못 함). 자유 사격은 양쪽 모두 2km 안.
- 시야: 고도 = 40 + sightElev × 330 (m). 시야 계산 간격 게임 0.5초.
- 이동 속도는 전차가 **현재 서 있는 칸**의 지형으로 결정.
- 경로 탐색: 8방향 A*. 대각선으로 통행 불가 칸 모서리를 스치는 이동 금지. 찾은 경로는 "원래 경로보다 느린 지형을 지나지 않는 지름길"만 허용해 직선화.
- 지도는 고정 시드로 생성되므로 항상 같은 모양.

### 확장 지침

- 새 기능은 새 파일로 만들고 `index.html` 의 스크립트 목록에 **의존 순서대로** 추가한다.
- 플레이어 지휘 명령은 `TMM.Command.issue` 를 거치게 한다 (지휘 전차는 바로, 나머지는 무전). 새 명령 종류는 `orders.js` 의 `execute/check/phrase/readback/describe` 와 `radio-net.js` 의 `mishear` 에 추가.
- 지형 수치는 `terrain-types.js`, 지형 모양은 `geography.js` 만 고치면 된다.
- 전투 수치(명중·관통·장전·탄약)는 `weapons.js`, 탐지·식별은 `sensors.js`, 지형의 가림은 `terrain-types.js` 의 `TERRAIN_SIGHT`, 적 행동 기준(교전 거리·집결·후퇴·퇴각 조건)은 `enemy-ai.js` 위쪽 상수, 적 경로는 `enemy.js` 만 고치면 된다.
- 전투 규칙은 DOM 없이 돌아가므로(`battle.js` 이하) Node 로 모의 전투를 수백 번 돌려 균형을 볼 수 있다: index.html 의 스크립트 중 render·input·ui·main 을 뺀 나머지를 `vm` 으로 읽고 `game = TMM.Battle.create({ light, rand })`, `TMM.Battle.step(game, 0.5)` 반복. 한 판에 약 2초.

## 6. 다음 단계 메모 (M8b 마무리 준비)

M8a 까지로 적 종류와 위협이 다 섰다. M8b(마무리)에서 할 일과 연결점:

- **난이도 선택**: 기본(지금) / 어려움(소대장 부상·전사 — `Crew.hurt` 의 `m.player` 제한, 흑표 거절 ↑, 실패 여파 ↑). 쉬움은 `TMM.SMOKE.CHARGES`·`TMM.MISSILE.AUTO_SMOKE_P` ↑, `TMM.INDIRECT.ARTY.WARN_SEC` ↑. 난이도는 캠페인 상태에 넣고 `Campaign.migrate` 에 기본값.
- **효과음**: 무전 잡음·발사·"미사일!" 경고음·포탄 낙하음. 경고 사건(`missile-warn`·`arty-warn`·`kami-warn`)이 이미 main.js `report()` 에 모여 있다.
- **새 위협 다듬기 후보**: 조준 화면에 미사일·드론·연막 구름 그리기(지금은 테두리 경고와, 내 전차가 연막 속이면 화면 전체가 뿌옇게만), 자폭 드론을 조준 화면에서 직접 쏘기, 연막을 던질 방향 고르기(지금은 위협 쪽 자동), 포병 대응 사격(대포병) 지원 요청, 대전차조 매복 자리 무작위.
- **저장 슬롯·캠페인 통계 화면**(작전별 사격·명중·피해·미사일 회피), 재정비 화면 모바일 정리, 헌터킬러, 이어지는 과제(아래).
- **균형 기준** (M8a 메모의 숫자): `good`+추천 재정비+흑표 완수 60~75%, 흑표를 부르든 안 부르든 차이 10%p 안, `naive`(대처 안 함)가 `good` 보다 확실히 낮고, `scope`·`passive` 는 대부분 소대 붕괴. 새 위협·난이도를 바꾸면 이 넷을 다시 돌린다.
- **모의 캠페인 방법**: `node tools/sim-campaign.js good 96` (4개로 나눠 돌리면 약 2분: 시드를 1, 100001, 200001, 300001 로). 직접 짜려면 '확장 지침'의 Node `vm` 방법(`tools/sim-load.js`)으로 읽고, `s = Campaign.newState(); s.phase = 'briefing'` → 반복 `{ Campaign.applyPlan(s); g = Battle.create({ op: Campaign.battleSpec(s), map, crew: s.crew, rand }); …st.events = Battle.step… ; Campaign.record(s, g); if (s.refitPending) Campaign.autoRefit(s, 'rec', rand); }` 를 `s.phase === 'ending'` 까지. 작전 하나만 볼 때는 `s.op = i` 로 시작.
- **저장 형식**: `state.v = 2` (키는 `tmm.campaign.v1` 그대로). M8a 는 저장 형식을 바꾸지 않았다. 필드를 바꾸면 `Campaign.migrate` 에 고쳐 읽기를 더한다.

### 이어지는 과제 (M6 까지에서)

- 조준 화면의 '포수에게 표적 넘기기'(헌터킬러), 이도현 이병의 탄종 실수가 '다른 탄이 실제로 들어감'이 되는 것, 모바일 조준 화면 정보 띠.
