# The Metal Man

한반도 전쟁 발발 직후 72시간, K1A2 전차 소대장이 되어 전차 4대를 지휘하는 브라우저 워게임입니다.

## 실행 방법

- **내 컴퓨터에서**: 저장소를 내려받은 뒤 `index.html` 을 더블클릭해 브라우저로 엽니다. 설치할 것은 없습니다.
- **GitHub Pages**: 저장소 Settings → Pages → Branch 를 `main` / `(root)` 로 저장하면 몇 분 뒤 공개 주소에서 실행됩니다.

## 처음 화면 (M7a)

- **새 캠페인**: 프롤로그(소대원 소개 + 짧은 교육) → 작전 5개(개전 첫 72시간) → 엔딩. 작전마다 작전 명령서를 보고 전차별 철갑탄/고폭탄 비율을 고른 뒤 출동합니다.
- 작전이 끝나면 전차 손상·남은 탄·승무원 부상·피로·사기·신뢰도가 다음 작전으로 이어집니다. 살아남은 전차가 2대 미만이 되면 '소대 붕괴'로 끝납니다.
- **재정비 (M7b)**: 작전 사이에 주어진 시간(4~6시간)을 나눠 씁니다. 다 할 수는 없으니 우선순위를 고르십시오.
  - 정비(궤도 4시간·엔진 5시간), 탄약 보급(1시간, 대대 보급 상황에 따라 받는 양이 다르고 작전 실패 뒤엔 줄어듦), 휴식(피로 회복), 부상자 처리(중상자 후송 또는 데리고 감, 경상자 남김 또는 후송).
  - 빈자리는 대대 보충병(신병)이나 다른 전차·후방 대기 승무원으로 채웁니다. 탄약수 없는 3명 K1A2 는 장전이 느립니다.
  - 전차를 잃으면 작전 2 이후 대대가 **K2** 를 보충해 줄 수 있습니다(최대 2대, 성과가 좋을수록 잘 옴). K2 는 승무원 3명·자동장전·더 빠름.
  - 재정비마다 승무원과의 짧은 대화 장면이 1~2개 나옵니다. 고른 대답에 따라 사기·신뢰도가 바뀝니다.
  - **추천대로 하기** 버튼을 누르면 알아서 골라 줍니다.
- 전투 중 1호차가 격파되면 소대장은 4호차로 옮겨 타서 계속 지휘합니다 (조준 화면도 4호차 기준). 기본 난이도에서 소대장은 죽지 않습니다.
- **이어하기**: 작전이 끝날 때마다 이 브라우저에 자동 저장됩니다. 창을 닫았다가 다시 열어도 이어서 할 수 있습니다 (전투 도중에 닫으면 그 작전의 명령 화면부터).
- **훈련 모드**: 캠페인과 상관없는 단일 전투 (주간/야간 선택).

## 조작법 (M6 기준)

1호차(소대장차)만 직접 움직이고, 2·3·4호차는 오른쪽 위 **무전 지휘** 창(또는 단축키)으로 명령합니다. 무전은 몇 초 늦게 도착하고, 가끔 잘못 알아듣거나 잡음에 묻힙니다.

| 조작 | 기능 |
|---|---|
| 전차 클릭 / 숫자키 1~4 | 전차 선택 (명령 받는 대상도 그 전차) |
| 5 · 6 · 7 | 받는 대상: 1조(1·2호차) · 2조(3·4호차) · 소대 전체 |
| M → 지도 클릭 | 이동 |
| C → 지도 클릭 | 엄호 (그 방향을 지켜보며 정지, 차체도 그쪽으로) |
| B → 지도 클릭 | 엄호 이동 (한 조가 엄호하는 동안 다른 조가 전진, 번갈아 반복) |
| T → 표적 클릭 | 목표 지정 (빈 곳 클릭은 해제). 표적을 바로 클릭해도 목표 지정 |
| W → 지도 클릭 | 철수 (처음엔 정면을 적에게 둔 채 후진) |
| S · R | 정지 · 상황 보고 요구 |
| K → 지도 클릭 | 이웃 K2 중대 '흑표'에 지원 요청 (작전마다 1번, 거절될 수 있음. 오면 K2 2대가 그 방향을 잠시 엄호) |
| 8 · 9 · 0 | 사격 금지 · 식별 후 사격 · 자유 사격 |
| 지도 클릭 (명령 없이) | 1호차 이동 |
| Q · X | 1호차 탄종 전환 · 목표 해제 |
| V | 선택한 전차의 시야 표시 |
| 스페이스바 | 일시정지 / 재개 (일시정지 중에도 명령 가능, 재개하면 전달 시작) |
| Esc / 오른쪽 클릭 | 고른 명령 취소 · 선택 해제 |
| 상단 ×1 ×2 ×4 | 시간 배속 |
| **Tab** | **1호차 조준 화면 ↔ 지도** |

### 1호차 조준 화면 (Tab)

소대장은 1호차 전차장이기도 합니다. 조준경을 들여다보면 1호차는 더 빠르고 정확하게 싸우지만, 그동안은 소대 무전 지휘를 못 합니다.

| 조작 | 기능 |
|---|---|
| 마우스 | 조준선 이동. 화면 가장자리로 가져가면 포탑이 그쪽으로 돎 (A·D·W·S / 화살표도 됨) |
| 좌클릭 | 발사 (조준선을 표적에 잠깐 유지하면 고리가 차오르고 더 잘 맞음) |
| L / 오른쪽 클릭 | 레이저 거리측정 (표적에 대고 재면 명중률이 크게 오름) |
| Q | 탄종 전환 |
| 휠 / Z | 배율 (광각 ×3 ↔ 협각 ×10) |
| 8 · 9 · 0 · R | 소대 전체 사격 통제 · 상황 보고 요구 (그 밖의 무전 명령은 불가) |
| Tab / Esc | 지도로 돌아가기 (지도에 있는 동안은 포수가 알아서 쏘지만 조금 느리고 덜 정확) |

일시정지 중에는 조준·사격이 안 됩니다. 소대 전차가 맞거나 교신이 끊기면 조준 화면 테두리가 깜빡입니다. 야간에는 열상 조준경(흑백, 뜨거운 것이 밝음)으로 보입니다.

## 개발 현황

설계와 단계별 계획은 [docs/DESIGN.md](docs/DESIGN.md) 를 보십시오. 현재 **M7b 재정비 깊이** 완료: 시간을 나눠 쓰는 재정비(정비·보급·휴식·부상자), 보충병·재배치, K2 보충과 혼성 소대, 이웃 K2 중대 지원, 재정비 중 승무원 이벤트. 다음은 M8(적 다양화와 마무리). Tab 키로 1호차 조준경에 들어가 직접 쏠 수 있고(M6), 전차마다 성격이 다른 승무원 4명이 타고(M5), 2·3·4호차는 소대장을 믿는 만큼 빠르고 정확하게 따릅니다.
