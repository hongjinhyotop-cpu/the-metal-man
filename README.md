# The Metal Man

한반도 전쟁 발발 직후 72시간, K1A2 전차 소대장이 되어 전차 4대를 지휘하는 브라우저 워게임입니다.

## 실행 방법

- **내 컴퓨터에서**: 저장소를 내려받은 뒤 `index.html` 을 더블클릭해 브라우저로 엽니다. 설치할 것은 없습니다.
- **GitHub Pages**: 저장소 Settings → Pages → Branch 를 `main` / `(root)` 로 저장하면 몇 분 뒤 공개 주소에서 실행됩니다.

## 조작법 (M2 기준)

| 조작 | 기능 |
|---|---|
| 전차 클릭 / 숫자키 1~4 | 전차 선택 |
| 지도 클릭 | 선택한 전차 이동 |
| 적 전차 클릭 | 선택한 전차의 사격 목표 지정 |
| Q | 탄종 전환 (K276 철갑탄 ↔ K277 고폭탄) |
| X | 사격 목표 해제 (가장 가까운 적과 자동 교전) |
| 스페이스바 | 일시정지 / 재개 |
| S | 선택한 전차 정지 |
| Esc / 오른쪽 클릭 | 선택 해제 |
| 상단 ×1 ×2 ×4 | 시간 배속 |
