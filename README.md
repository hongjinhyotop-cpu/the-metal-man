# The Metal Man

한반도 전쟁 발발 직후 72시간, K1A2 전차 소대장이 되어 전차 4대를 지휘하는 브라우저 워게임입니다.

## 실행 방법

- **내 컴퓨터에서**: 저장소를 내려받은 뒤 `index.html` 을 더블클릭해 브라우저로 엽니다. 설치할 것은 없습니다.
- **GitHub Pages**: 저장소 Settings → Pages → Branch 를 `main` / `(root)` 로 저장하면 몇 분 뒤 공개 주소에서 실행됩니다.

## 처음 화면 (M7a)

- **새 캠페인**: 프롤로그(소대원 소개 + 짧은 교육) → 작전 5개(개전 첫 72시간) → 엔딩. 작전마다 작전 명령서를 보고 전차별 철갑탄/고폭탄 비율을 고른 뒤 출동합니다.
- 작전이 끝나면 전차 손상·남은 탄·승무원 부상·피로·사기·신뢰도가 다음 작전으로 이어집니다. 살아남은 전차가 2대 미만이 되면 '소대 붕괴'로 끝납니다.
- **재정비 (M7b)**: 작전 사이에 주어진 시간(4~6시간)을 나눠 씁니다. 다 할 수는 없으니 우선순위를 고르십시오.
  - 정비(궤도 4시간·엔진 5시간), 탄약 보급(1시간, 대대 보급 상황에 따라 받는 양이 다르고 작전 실패 뒤엔 줄어듦), 휴식(피로 회복), 부상자 처리(중상자 후송 또는 데리고 감, 경상자 남김 또는 후송).
  - 빈자리는 대대 보충병(신병)이나 다른 전차·후방 대기 승무원으로 채웁니다. 탄약수 없는 3명 K1A2 는 장전이 느립니다.
  - 전차를 잃으면 작전 2 이후 대대가 **K2** 를 보충해 줄 수 있습니다(최대 2대, 성과가 좋을수록 잘 옴). K2 는 승무원 3명·자동장전·더 빠름.
  - 재정비마다 승무원과의 짧은 대화 장면이 1~2개 나옵니다. 고른 대답에 따라 사기·신뢰도가 바뀝니다.
  - **추천대로 하기** 버튼을 누르면 알아서 골라 줍니다.
- 전투 중 1호차가 격파되면 소대장은 4호차로 옮겨 타서 계속 지휘합니다 (조준 화면도 4호차 기준). 기본 난이도에서 소대장은 죽지 않습니다.
- **이어하기**: 작전이 끝날 때마다 이 브라우저에 자동 저장됩니다. 창을 닫았다가 다시 열어도 이어서 할 수 있습니다 (전투 도중에 닫으면 그 작전의 명령 화면부터).
- **훈련 모드**: 캠페인과 상관없는 연습.
  - **기초 훈련** (처음이라면 여기부터): 짧은 3단계로 조작을 익힙니다 — ① 1호차를 골라 표시된 곳으로 이동 ② 2조에게 우클릭 메뉴로 엄호 명령 ③ 나타난 적에게 목표 지정. 화면 위에 할 일이 한 줄로 나오고, 해내면 다음 단계로 넘어갑니다.
  - **실전 훈련**: 단일 전투 (주간/야간 선택).

## 조작법 (M7.5 — 마우스만으로 다 됩니다)

1호차(소대장차)만 직접 움직이고, 2·3·4호차는 무전으로 명령합니다. 무전은 몇 초 늦게 도착하고, 가끔 잘못 알아듣거나 잡음에 묻힙니다.
헷갈리면 언제든 오른쪽 위 **[? 조작법]** 또는 **F1** 을 누르면 조작 요약 카드가 뜹니다.

### 마우스

| 할 일 | 어떻게 |
|---|---|
| 전차 고르기 | 지도의 **전차 아이콘 클릭**, 또는 오른쪽 **[1조] [2조] [소대 전체]** 큰 버튼 (호차 버튼 4개도 있음) |
| 이동 · 엄호 · 철수 | **지도(땅)를 우클릭** → 메뉴에서 고르기. 엄호 = 그 방향을 지켜보며 정지 |
| 목표 지정 | **적을 우클릭** → [목표 지정] (또는 적을 그냥 클릭) |
| 정지 · 상황 보고 | **내 전차를 우클릭** → 메뉴 (지휘 전차면 탄종 전환·조준 화면도) |
| 1호차 이동 | 1호차를 고른 상태에서 **지도 클릭** |
| 명령 버튼 | 오른쪽 명령 버튼(아이콘 + 이름 + 단축키)을 누르고 지도를 클릭해도 됩니다. 마우스를 올리면 한 줄 설명 |
| 일시정지 / 재개 | 맨 위 **[▶ 작전 개시] / [❚❚ 진행 중]** 단추 |
| 조준 화면 | 오른쪽 **[조준 화면]** 단추, 돌아올 때는 왼쪽 위 **[◀ 지도로]** |
| 시야 표시 | 지도 왼쪽 위 **[시야 표시]** 단추 |
| 고른 명령 취소 | 우클릭 (또는 Esc) |

지도 아래 안내 줄이 **지금 클릭하면 무슨 일이 생기는지** 알려 줍니다 (예: "2조 선택됨 · 지도를 우클릭해 명령").

### 화면: 간단 보기 / 상세 보기

- **간단 보기**(기본): 오른쪽 창에 누구에게 · 고른 전차 요약 한 줄(호차·상태·남은 탄) · 명령 버튼 · 무전 기록 최근 5줄만. 승무원 잡담은 줄이고, 피격·격파·경고는 색 막대로 강조합니다.
- 나머지(선택 전차 상세·승무원, 접촉 현황, 소대 현황, 지도 기호·지형)는 접혀 있습니다. 제목을 누르면 펼쳐집니다.
- **상세 보기** 버튼 하나로 모두 펼치고, 무전 기록 전체, 모든 전차의 엄호 부채꼴을 봅니다.
- 지도 위 사거리 원·엄호 부채꼴·사격선은 고른 전차 것만 보입니다.

### 꼭 알아 둘 단축키 (몰라도 됩니다)

메뉴와 버튼에 단축키가 같이 적혀 있어서 쓰다 보면 외워집니다.

| 키 | 기능 |
|---|---|
| 스페이스바 | 일시정지 / 재개 (멈춘 채 명령 가능, 재개하면 전달 시작) |
| Tab | 1호차 조준 화면 ↔ 지도 |
| 1~4 · 5 · 6 · 7 | 전차 고르기 · 1조 · 2조 · 소대 전체 |
| M · C · W → 지도 클릭 | 이동 · 엄호 · 철수 |
| T → 표적 클릭 | 목표 지정 (빈 곳은 해제) |
| S · R | 정지 · 상황 보고 |
| Esc | 취소 · 메뉴 닫기 |
| F1 (또는 ?) | 조작 요약 카드 |

그 밖의 키도 그대로 됩니다 (버튼으로도 됨): B 엄호 이동(한 조가 엄호하는 동안 다른 조가 전진) · K 흑표 지원 요청(이웃 K2 중대, 작전마다 1번) · 8·9·0 사격 금지·식별 후 사격·자유 사격 · Q 1호차 탄종 전환 · X 목표 해제 · V 시야 표시 · 상단 ×1 ×2 ×4 시간 배속.

### 1호차 조준 화면 ([조준 화면] 단추 또는 Tab)

소대장은 1호차 전차장이기도 합니다. 조준경을 들여다보면 1호차는 더 빠르고 정확하게 싸우지만, 그동안은 소대 무전 지휘를 못 합니다.

| 조작 | 기능 |
|---|---|
| 마우스 | 조준선 이동. 화면 가장자리로 가져가면 포탑이 그쪽으로 돎 (A·D·W·S / 화살표도 됨) |
| 좌클릭 | 발사 (조준선을 표적에 잠깐 유지하면 고리가 차오르고 더 잘 맞음) |
| L / 오른쪽 클릭 | 레이저 거리측정 (표적에 대고 재면 명중률이 크게 오름) |
| Q | 탄종 전환 |
| 휠 / Z | 배율 (광각 ×3 ↔ 협각 ×10) |
| 8 · 9 · 0 · R | 소대 전체 사격 통제 · 상황 보고 요구 (그 밖의 무전 명령은 불가) |
| [◀ 지도로] / Tab / Esc | 지도로 돌아가기 (지도에 있는 동안은 포수가 알아서 쏘지만 조금 느리고 덜 정확) |

일시정지 중에는 조준·사격이 안 됩니다. 소대 전차가 맞거나 교신이 끊기면 조준 화면 테두리가 깜빡입니다. 야간에는 열상 조준경(흑백, 뜨거운 것이 밝음)으로 보입니다.

## 개발 현황

설계와 단계별 계획은 [docs/DESIGN.md](docs/DESIGN.md) 를 보십시오. 현재 **M7.5 조작·화면 정리** 완료: 마우스만으로 하는 조작(우클릭 메뉴·조 버튼·안내 줄·조작 요약 카드), 간단/상세 보기, 기초 훈련. 그 앞의 **M7b 재정비 깊이**: 시간을 나눠 쓰는 재정비(정비·보급·휴식·부상자), 보충병·재배치, K2 보충과 혼성 소대, 이웃 K2 중대 지원, 재정비 중 승무원 이벤트. 다음은 M8(적 다양화와 마무리). Tab 키로 1호차 조준경에 들어가 직접 쏠 수 있고(M6), 전차마다 성격이 다른 승무원 4명이 타고(M5), 2·3·4호차는 소대장을 믿는 만큼 빠르고 정확하게 따릅니다.
